# better-web-ui — project design context

Personal one-page landing for **Евгений Колесников** (editor, content strategist, project lead).
Source of truth for the brief: `content.txt`. This file captures the *design* decisions
derived from it so future sessions do not re-derive them.

## Design Context

### Users

- **Primary:** decision-makers at tech/product companies and media who need an editor — heads of
  content, marketing, HR, DevRel, founders. They scan for proof of judgement and measurable
  outcome, not for craft vocabulary.
- **Secondary:** the editorial community itself (Habr, DTF, vc.ru) — peers who read the writing
  and the links.
- **Job to be done:** within 30–60 seconds decide "this is a strong editor who can structure
  complex technical content" and start a conversation in Telegram.
- **Reading context:** mostly desktop, often on a phone, one visit, from a link in a bio or a
  messenger. Not a returning audience, so no in-site orientation help is required.

### Brand Personality

Confident, intellectual, slightly strict, modern. Not corporate, not agency-like, not sterile.
Editorial authority rather than startup energy.

### Aesthetic Direction

- **Primary structural direction:** Editorial Style (magazine composition, strong headline
  contrast, asymmetric spreads, hairline rules instead of cards).
- **Supporting modifier:** Swiss grid discipline (modular 12-column grid, controlled asymmetry,
  letterspaced micro-labels). No glass, no bento, no 3D, no gradients.
- **Metaphor:** the editorial craft — rules, columns, marks, indices, annotations, measure.
  Never a literal text-editor pastiche.
- **Base:** warm paper (`oklch(0.977 0.006 85)`), near-black warm ink
  (`oklch(0.19 0.012 60)`), one accent — proofreader's vermilion
  (`oklch(0.552 0.184 31)`, deep variant `oklch(0.468 0.176 30)` for small text).
  The closing section drops to an ink plate so the page ends on contrast rather
  than on a technical footer strip.
- **Dark theme is designed, not inverted.** Surfaces become warm charcoal
  (`oklch(0.205 0.010 63)`), not blue-black; elevation reads as a *lighter*
  surface, not a heavier shadow; hairlines lighten instead of darkening; the
  accent lifts in lightness so it still clears 4.5:1. The closing plate goes one
  step deeper than the page so the terminus still reads.
- **Photography:** the author's real studio portraits are dark, warm and low-key. They are used
  as **dark plates** on the paper page, never as decorative cutouts. Originals live in
  `~/Pictures/portrait-{1,2,3}.png`; `portrait-2` is the hero — re-cropped to 4:5
  (`public/assets/portrait-hero.webp`, 64 KB, down from 2.1 MB PNG) with a 16:10
  `object-position` variant for tablet. No photography elsewhere: the manifesto
  section earns its weight from type alone.
- **Anti-references:** AI SaaS aesthetic, purple/acid gradients, glassmorphism, blurred blobs,
  bento grids, identical rounded cards, oversized buttons, stock photography, heavy shadows,
  large radii, decorative motion.

### Implementation Defaults

- **Framework/runtime:** React 19 + Vite 8 + TypeScript 7, function components only.
  No router, no state library, no CSS-in-JS — a single static route with anchor navigation.
- **Styling:** Tailwind CSS v4 via `@tailwindcss/vite`, with a shadcn-style semantic token
  layer declared in `src/index.css`. This is what makes
  `bg-background`, `text-foreground`, `border-border`, `text-muted-foreground`,
  `bg-card`, `text-accent`, `ring-ring` resolve. A `.plate-ink` scope re-points the same
  tokens at the plate primitives, so no section hardcodes hex values.
  Fluid type and spacing via `clamp()`; breakpoints are plain `sm/md/lg/xl`.
- **Theming:** two-layer custom properties. `--p-*` are palette primitives, redefined
  per theme; `--background`/`--foreground`/`--card`/`--border`/`--accent` map from the
  primitives exactly once and never change. Because the mapping holds an unresolved
  `var()`, redefining a primitive under `[data-theme='dark']` re-resolves every consumer —
  one palette block per theme, no duplication, no class juggling.
  `src/hooks/useTheme.ts` owns the three-state preference (light / dark / system),
  persists it to `localStorage.theme`, and follows the OS live while on "system".
  An inline script in `index.html` resolves the theme *before first paint* so there is no
  flash; it must stay in sync with the hook. `ThemeToggle` is a three-segment control in
  the masthead with `aria-pressed` on each segment.
- **Icons:** `lucide-react`, named imports only (tree-shaken): `Send`, `Mail`, `FileText`,
  `ArrowUpRight`, `ArrowUp`, `Compass`, `Workflow`, `Target`, `Sun`, `Moon`, `Monitor`.
- **Fonts:** Google Fonts — **Spectral** (display serif, full Cyrillic) and **Onest**
  (variable grotesque 100–800, full Cyrillic), loaded with `preconnect` + `display=swap`.
  Chosen over Inter explicitly; Playfair Display was rejected because its Cyrillic subset
  covers a single weight, so a large-weight Cyrillic headline would silently fall back.
- **Motion:** one `IntersectionObserver` hook (`useInView`) behind `Reveal` / `Rule`. CSS owns
  every duration and easing token; components only pass a stagger delay. No animation loops.
  `prefers-reduced-motion` disables all of it and shows content immediately. Theme swaps
  cross-fade only while `.theme-switching` is on the root, so hover and reveal transitions
  are never interrupted.
- **Assets:** WebP via Pillow, explicit `width`/`height` to prevent layout shift,
  `fetchpriority="high"` on the hero plate.
- **Verification:** `scripts/render.mjs` renders the real component tree to
  `dist/rendered.html`; `scripts/audit.py` checks that DOM for verbatim copy, superseded
  strings that must stay gone, the seven mandated links, heading order, landmarks, dead
  anchors, image attributes, focus and reduced-motion support, the theme wiring, and a
  total asset budget. Run `npm run verify` before shipping any copy change.

### Design Principles

1. **Typography is the brand.** Hierarchy comes from size, weight, measure and letterspacing
   before any other device. If a section looks weak, fix the type scale, not the decoration.
2. **One accent, used as meaning.** Vermilion marks editorial marks — section indices, growth
   figures, focus, primary action. Never fills a background, never decorates.
3. **Rules instead of cards — but earned.** Hairlines and whitespace do the structural work.
   Where a card is genuinely the right unit (services, cases) it is a `rounded-2xl`
   `border-border` `bg-card` `shadow-plate` surface, and the *grid cadence* carries the
   asymmetry (7/5/7/5), never a different visual language per tile. Cards lift to
   `shadow-lift` plus an accent top rule on hover.
4. **Asymmetric measure, generous air.** Text columns stay at 45–75 characters
   (`.measure` = 62ch, `.measure-tight` = 46ch). Inter-section whitespace is
   `py-16 / md:py-24 / lg:py-28` — tuned down from an excessive start until the page
   felt balanced. Columns are balanced by construction, never by leftover space: the hero
   credentials and the manifesto plate both fill their column.
5. **Unequal emphasis is intentional.** Sections must not look like six equal template blocks:
   the metrics block is the loudest (figures at display scale, `1px` rule grid, sunk band)
   and the closing plate is the second loudest (ink, index + full-width rule). The closing
   line itself is body copy, not a headline — the plate and the contact row carry the
   emphasis, so the page ends on contrast rather than on a slogan.
6. **Motion confirms, never performs.** Reveals, hovers and one orchestrated page load. Nothing
   loops. Everything yields to `prefers-reduced-motion`.
7. **Copy is untouchable.** Formulations, figures, names and links come verbatim from the brief.
   Only hierarchy, measure, line breaks and block structure may change. All copy lives in
   `src/content.ts` as the single source of truth — components never inline strings, so a
   copy edit is a one-file change and `npm run verify` proves nothing drifted.
